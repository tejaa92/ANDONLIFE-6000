# ANDONLIFE-6000 - data dictionary and validation

Fully synthetic andon event-lifecycle dataset: 6,000 events, 40 synthetic facilities, 12 synthetic months. Generated by generate_eandon_events.py (Python standard library only, seed 7). Files: andonlife6000_events.csv / andonlife6000_events.json.

## Fields
- event_id: EV00001-EV06000.
- facility_id / facility_archetype: F01-F40; archetypes assembly, machining, fabrication, paint_finish (10 each), with a fixed per-facility size/efficiency factor drawn once from U(0.8, 1.3).
- month: 1-12 (synthetic). shift: 1-3.
- category: equipment_downtime, material_shortage, process_deviation, quality, manpower, station_starvation, safety (shares 0.30/0.16/0.14/0.13/0.10/0.09/0.08). Category set mirrors the documented eAndon incident taxonomy in the work records.
- trigger_source: kiosk, tablet, hmi (manual) or automated_plc_rule. Automated probability rises linearly from 6% in month 1 to 46% in month 12 - a disclosed modeling choice representing automation rollout after an API release; it is not a claim about any real deployment.
- ack_minutes / resolve_minutes / close_minutes: lognormal draws (sigma 0.55) around category base medians, multiplied by trigger factors (automated ack x0.45, resolve x0.80), archetype effect (0.95-1.10), and the facility factor. close = resolve + a lognormal administrative lag (median 18 min). final_state is "closed" for all records (the dataset models completed lifecycles).
- escalated / escalation_level: escalated if resolve > 120 min, or safety events with p=0.35, or a background p=0.08; level 2 if resolve > 240 min else 1.
- downtime_minutes: nonzero only for equipment_downtime (lognormal around an 85-min median, scaled by archetype and facility factors).
